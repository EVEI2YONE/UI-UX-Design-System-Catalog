# Reusable packages — future capability

**No installable UI component package or token distribution is shipped by this repository today.** Component specs are under [specifications/components](../specifications/components/), and synthetic references remain under [site/src/implementations](../site/src/implementations/).

Only introduce a package after it has a consumer-facing API, packaging/install instructions, versioning, ownership, tests, compatibility policy, and real adopters. Do not use reference demo source as an unreviewed release.
