# Start with a user task

Choose a user goal first, then follow its owning canonical pattern, component contract, content guidance, evidence, and implementation examples. This is a **discovery index**, not a second body of normative rules.

| Task family | Example task | Canonical starting point |
| --- | --- | --- |
| Find and discover | Narrow a long list; expose applied filters | [Search and filtering](../specifications/patterns/search-and-filter.md) |
| Understand and compare | Compare records by shared attributes | [Data tables](../specifications/patterns/data-tables.md) |
| Recover and resume | Recover from a no-results state or service failure | [Interaction states and recovery](../specifications/patterns/interaction-states-and-recovery.md) |
| Enter and complete | Complete a form in reading order | [Form composition](../specifications/patterns/forms.md) |
| Recover and resume | Correct failed form submission without losing work | [Forms](../specifications/patterns/forms.md) + [Field](../specifications/components/field/spec.md) |
| Decide and confirm | Review consequential answers before submission | [Task flows](../specifications/patterns/task-flows-and-information-architecture.md) |
| Decide and confirm | Confirm destructive actions | [Dialog](../specifications/components/dialog/spec.md) + [recovery](../specifications/patterns/interaction-states-and-recovery.md) |
| Monitor and manage | Sort, inspect, and act on a collection | [Data tables](../specifications/patterns/data-tables.md) |
| Configure and personalize | Change account settings and preferences | [Account/settings portal](../specifications/patterns/account-and-settings-portal.md) |
| Learn and onboard | Understand first actions and progressive disclosure | [Task flows](../specifications/patterns/task-flows-and-information-architecture.md) |

## Recipe format

Each future canonical task recipe should capture: **user goal and context → use/avoid rules → suitable patterns and components → content and visual direction → states → a11y/i18n → examples → research provenance and limitations → acceptance criteria → owner and status**.

Consult [AGENTS.md](../AGENTS.md) for current AI retrieval procedure and [catalog/index.json](../catalog/index.json) for authoritative concept metadata. Do not promote an example or an externally researched suggestion to a universal rule.
