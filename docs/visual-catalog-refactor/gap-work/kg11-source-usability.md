# Source exploration and optional distribution

**Knowledge-gap IDs:** KG-11  
**Status:** open work package — not completed or approved  
**Origin:** [original gap audit](../03-knowledge-gap-audit.md) and [durable concept / closure ledger](../17-concept-inventory-and-decisions.md)  
**Recorded:** 2026-11-08 · **Accountability:** Developer-experience and catalog reviewer (role only; no named assignee)

## Why the gap remains

The site shows actual source and source provenance, but source copy/download conveniences and packaging are not implemented. Distribution was explicitly optional and is not necessary for a trustworthy catalog.

## Recommended work

Task-test whether visitors can find and reuse source; evaluate a copy-source control with attribution, keyboard and clear language; distinguish selected code from complete adapter/scenario dependencies; decide against package publishing unless there is justified demand.

## Acceptance evidence required

User-task observations, link/attribution behavior tests, source parity and documented go/no-go on copy/download or packaging.

## Nonclaims and deferral rule

Do not label partial source copied from an iframe a production-ready installation artifact.

This is a **repository-only durable follow-up**, not a live website concept, canonical catalog ID or a new executable implementation. Keep status open until the specified review produces evidence; if the requirement is rejected or waived, record the responsible owner and decision rather than silently deleting the work package.
