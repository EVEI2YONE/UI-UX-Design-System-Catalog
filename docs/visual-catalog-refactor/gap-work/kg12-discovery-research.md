## Why the gap remains

Lexical retrieval and one scripted Chromium task were verified, but no participant research or task-level comprehension/efficiency baseline was collected. The phrase synthetic review is still a known query miss.

## Recommended work

Design user and agent task sets for navigation, source trust, empty/spec-only semantics and feature-vs-pattern selection; recruit representative users where possible; record first-hit usefulness, time-to-correct-reference, confusion, perceived trust and accessibility failures. Compare proposed search improvements against existing deterministic ranking before editing aliases.

## Acceptance evidence required

Study protocol, participant/environment coverage, anonymized observations, reproducible task corpus and decision log with measured baseline and follow-up.
