# Component specifications

Normative contracts, states and interaction decisions (not published packages). Every item links to its one canonical source file. Entries remain proposed until separately reviewed; implementation examples do not imply a deployable library.

| Concept | Canonical ID | When relevant |
| --- | --- | --- |
| [Button](button/spec.md) | `component.button` | Initiate actions with semantic states and safe async activation. |
| [Checkbox](checkbox/spec.md) | `component.checkbox` | Express independent Boolean choices and group selection. |
| [Combobox and autocomplete](combobox/spec.md) | `component.combobox` | Editable choice with a suggestion popup and explicit committed value. |
| [Date and time input](date-time-input/spec.md) | `component.date-time-input` | Locale-aware date/time entry with unambiguous time-zone interpretation. |
| [Dialog](dialog/spec.md) | `component.dialog` | Reusable modal shell with focus, dismissal and accessible semantics. |
| [Disclosure and accordion](disclosure/spec.md) | `component.disclosure` | Collapsible optional content with expansion semantics and focus recovery. |
| [Field and error](field/spec.md) | `component.field` | Compose persistent label, help and field-error associations. |
| [Hierarchical tree view](tree-view/spec.md) | `component.tree-view` | Expand and select hierarchical items with consistent focus and keyboard navigation. |
| [Input](input/spec.md) | `component.input` | Single-line editable input with labels, values and validation hooks. |
| [Menu button and action menu](menu-button/spec.md) | `component.menu-button` | Action menu trigger, item semantics, dismissal and keyboard operation. |
| [Popover and non-modal overlay](popover/spec.md) | `component.popover` | Contextual interactive overlay without inappropriate modal focus trapping. |
| [Radio group](radio-group/spec.md) | `component.radio-group` | Mutually exclusive choices with group labeling and native radio semantics. |
| [Select](select/spec.md) | `component.select` | Select a single known option using native semantics where possible. |
| [Slider and bounded range control](slider/spec.md) | `component.slider` | Select a value on a bounded scale with keyboard and precision alternatives. |
| [Switch and immediate toggle](switch/spec.md) | `component.switch` | Binary on/off setting with truthful immediate and persisted states. |
| [Tabs and tab panels](tabs/spec.md) | `component.tabs` | Peer content panels with a documented selection and keyboard model. |
| [Textarea and long-form input](textarea/spec.md) | `component.textarea` | Multiline editing, validation, text growth and reliable draft states. |
| [Tooltip](tooltip/spec.md) | `component.tooltip` | Noninteractive supporting explanation for hover or keyboard focus. |
