# Component specifications

Normative contracts, states and interaction decisions (not published packages). Every item links to its one canonical source file. Entries remain proposed until separately reviewed; implementation examples do not imply a deployable library.

| Concept | Canonical ID | When relevant |
| --- | --- | --- |
| [Button](button/spec.md) | `component.button` | Initiate actions with semantic states and safe async activation. |
| [Checkbox](checkbox/spec.md) | `component.checkbox` | Express independent Boolean choices and group selection. |
| [Dialog](dialog/spec.md) | `component.dialog` | Reusable modal shell with focus, dismissal and accessible semantics. |
| [Field and error](field/spec.md) | `component.field` | Compose persistent label, help and field-error associations. |
| [Input](input/spec.md) | `component.input` | Single-line editable input with labels, values and validation hooks. |
| [Select](select/spec.md) | `component.select` | Select a single known option using native semantics where possible. |

Find related guidance by [task](../../tasks/README.md) or [registry ID](../../catalog/index.json).
